# Pi-Guard Lite 使用说明

## 1. 系统用途

Pi-Guard Lite 用于：

- 接收 Suricata / 系统日志
- 解析事件
- 提取特征
- 结合规则、基线、ML 打分
- 自动生成策略
- 执行封禁
- 做探测与回滚

---

## 2. 常用脚本

### 2.1 生成演示模型

```powershell
python scripts\create_demo_models.py
```

### 2.2 处理 Suricata 样例

```powershell
python scripts\process_suricata_file.py tests\samples\suricata_eve.jsonl --apply-policy --run-probe
```

### 2.3 运行主链路服务

```powershell
python scripts\run_pipeline_service.py --source suricata --file tests\samples\suricata_eve.jsonl --mode existing
```

### 2.4 释放过期封禁

```powershell
python scripts\release_expired_blocks.py
```

### 2.5 导入模型

```powershell
python scripts\import_model.py anomaly models\anomaly_model.pkl --version demo-anomaly
python scripts\import_model.py classifier models\classifier_model.pkl --version demo-classifier
```

### 2.6 Linux 运维脚本

```bash
bash scripts/install.sh
bash scripts/start.sh
bash scripts/stop.sh
bash scripts/backup.sh
```

### 2.7 Fluent Bit 接入

```powershell
Get-Content tests\samples\fluentbit_syslog.jsonl | python scripts\run_fluentbit_stdin.py --no-policy --no-probe
```

真实环境可参考：

- `config/fluent-bit.conf`

## 6. 运行建议

### 开发环境
- `dry_run=true`
- probe 使用本地健康检查
- 使用 demo 模型

### 真机环境
- `dry_run=false`
- 更换成真实 OpenWrt / 防火墙命令
- 配置真实 probe 目标
- 导入真实训练模型

---

## 7. 排查建议

### 无事件
- 检查输入文件路径
- 检查解析器 source 是否匹配
- 检查原始日志是否写入 `data/raw/`

### 无策略
- 检查风险分是否达到阈值
- 检查白名单是否命中
- 检查 policy generator 输出

### 无封禁
- 检查 `executor.yaml`
- 检查 `dry_run`
- 检查 `/executor/check`

### 总是回滚
- 检查 `probe.default_targets`
- 检查 `/health`
- 检查 probe 目标可达性
