# Pi-Guard Lite 场景测试说明

## 1. 目标

本文档用于快速验证项目主链路是否仍然可用。

---

## 2. 当前内置场景

### 2.1 Suricata 攻击样例

输入：

- `tests/samples/suricata_eve.jsonl`

覆盖：

- 告警事件
- DNS 可疑查询
- HTTP 登录类请求
- 策略生成
- 封禁落库

### 2.2 auth.log 登录失败

输入：

- `tests/samples/auth.log`

覆盖：

- 系统认证失败解析
- 风险打分

### 2.3 Fluent Bit JSON 行

输入：

- `tests/samples/fluentbit_syslog.jsonl`

覆盖：

- Fluent Bit 输入转换
- syslog 进入主链路

---

## 3. 场景测试命令

### 3.1 一次性场景测试脚本

```powershell
python scripts\run_scenario_tests.py
```

### 3.2 单元测试

```powershell
python -m unittest tests\test_scenario_runner.py
python -m unittest tests\test_pipeline_integration.py
```

---

## 4. 通过标准

至少满足：

1. 能成功处理 Suricata 样例
2. 关键告警能生成策略
3. blocklist 有新增记录
4. auth.log 可被识别为 `system.auth_failure`
5. Fluent Bit JSON 行可被接入

---

## 5. 推荐测试顺序

1. `python scripts\create_demo_models.py`
2. `python scripts\run_scenario_tests.py`
3. `python -m unittest tests\test_scenario_runner.py`
4. 再跑全量测试
