# Pi-Guard Lite 数据清理与保留说明

## 1. 目标

控制 `data/raw`、`logs`、`backups` 的文件保留时间，避免树莓派磁盘被逐渐占满。

---

## 2. 配置项

位置：

- `config/app.yaml -> retention`

```yaml
retention:
  cleanup_enabled: true
  raw_days: 7
  log_days: 7
  backup_days: 30
```

---

## 3. 清理脚本

```powershell
python scripts\cleanup_runtime_data.py
```

会清理：

- `data/raw`
- `logs`
- `backups`

仅删除超过保留天数的文件，不会删除 `.gitkeep`。

---

## 4. systemd 定时任务

项目已提供：

- `systemd/pi-guard-lite-cleanup.service`
- `systemd/pi-guard-lite-cleanup.timer`

建议在树莓派上启用。

---

## 5. 使用建议

### 开发环境

- `raw_days=7`
- `log_days=7`
- `backup_days=30`

### 树莓派环境

根据存储大小调整：

- microSD 紧张时，可把 `raw_days` 降到 `3`
- 日志较多时，可把 `log_days` 降到 `3~5`

---
