# Pi-Guard Lite 本机扫描演示说明

## 1. 目标

在当前开发机上直接发起一次真实 TCP 端口扫描，并让 Pi-Guard Lite 进行检测和策略生成。

---

## 2. 演示命令

```powershell
python scripts\run_live_scan_demo.py
```

---

## 3. 演示过程

脚本会自动完成：

1. 启动一组本地监听端口
2. 对这些端口发起真实 TCP 扫描
3. 将连接事件送入 Pi-Guard Lite 主链路
4. 输出：
   - 扫描结果
   - 事件
   - 策略
   - 黑名单

---

## 4. 演示结果重点

你要关注输出里的：

- `events`
- `policies`
- `blocklist`

当系统观察到同一来源对大量不同目标端口进行访问时，会识别为：

- 端口扫描

并生成：

- `block_ip`

---

## 5. 说明

这是本机真实 TCP 扫描演示，不是样例重放。

为保证本机回环地址能被检测，项目对 `scan.demo` 源做了演示级白名单绕过处理，仅用于本机演示。
