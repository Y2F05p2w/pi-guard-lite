# Pi-Guard Lite 树莓派上线手册

## 1. 目标

本文档用于树莓派到货后，把当前代码真正部署到 Raspberry Pi 上。

---

## 2. 上线前准备

### 2.1 硬件

- Raspberry Pi 4B 4GB 或 Pi 5 2GB
- microSD / SSD
- 电源
- 网络

### 2.2 软件

- Raspberry Pi OS Lite 64-bit
- SSH 可用
- 已联网

---

## 3. 首次开机后要做的事

1. 更新系统
2. 配置时区
3. 配置静态 IP
4. 开启 SSH
5. 安装 Python 3、venv、git
6. 安装 Fluent Bit（如要真机接入）
7. 安装 Suricata（如要真机流量接入）

---

## 4. 部署代码

```bash
cd /opt
git clone git@github.com:Y2F05p2w/pi-guard-lite.git
cd pi-guard-lite
bash scripts/install.sh
```

---

## 5. 修改关键配置

### `config/app.yaml`
- `probe.default_targets`
- `ml.enabled`
- 评分参数

### `config/executor.yaml`
- `host`
- `username`
- `password` 或 `key_path`
- `dry_run=false`
- block / unblock 命令模板

### `config/assets.yaml`
- 真实资产清单

### `config/whitelist.yaml`
- 内网白名单
- 管理员 IP

### `config/fluent-bit.conf`
- auth/syslog/nginx 日志真实路径

---

## 6. 模型准备

### 演示模式

```bash
python scripts/create_demo_models.py
```

### 真实模型导入

```bash
python scripts/import_model.py anomaly /path/to/anomaly.pkl --version rpi-v1
python scripts/import_model.py classifier /path/to/classifier.pkl --version rpi-v1
```

---

## 7. 启动方式

### 手工启动

```bash
bash scripts/start.sh
```

### systemd 启动

复制并启用：

- `systemd/pi-guard-lite.service`
- `systemd/pi-guard-lite-pipeline.service`
- `systemd/pi-guard-lite-release-expired.timer`

如果使用 Fluent Bit 桥接：

- `systemd/pi-guard-lite-fluentbit.service`

---

## 8. 真机验证顺序

1. `/health` 正常
2. `/executor/check` 正常
3. 手工封禁 / 解封可用
4. `run_pipeline_service.py` 可处理样例
5. Fluent Bit 真机日志可进链路
6. Suricata 真机日志可进链路
7. Probe 可访问核心业务
8. 回滚逻辑正常

---

## 9. 上线时建议

- 第一阶段保持 `dry_run=true`
- 先跑只告警
- 确认探测目标可靠后再打开自动封禁
- 先短 TTL，后逐步放大

---

## 10. 上线后观察项

- CPU / 内存
- 温度
- 日志增长
- SQLite 文件大小
- 误报率
- 自动回滚频率
