# Pi-Guard Lite 树莓派运行检查说明

## 1. 目标

树莓派到货并部署后，用于快速检查运行环境、服务状态和基础资源。

---

## 2. 脚本

### 运行环境报告

```bash
python scripts/collect_runtime_report.py
```

输出：

- 主机信息
- Python 版本
- 关键二进制是否存在
- systemd 服务状态
- 磁盘使用情况
- CPU 温度（可读取时）

### 服务状态检查

```bash
bash scripts/verify_rpi_services.sh
```

输出：

- `pi-guard-lite.service`
- `pi-guard-lite-pipeline.service`
- `pi-guard-lite-fluentbit.service`
- `pi-guard-lite-release-expired.timer`
- `/health` 结果

---

## 3. 推荐使用时机

1. 树莓派首次部署完成后
2. 每次修改 systemd 配置后
3. 开始真机联调前
4. 稳定性测试前后

---

## 4. 通过标准

至少满足：

1. 关键服务 active
2. `/health` 可访问
3. `fluent-bit`/`suricata` 至少按目标部署状态可见
4. CPU 温度无明显异常
5. 磁盘空间充足
