# Pi-Guard Lite 模型训练与调优说明

## 1. 目标

本文档说明如何用真实或样例特征数据训练模型，并导入到 Pi-Guard Lite。

---

## 2. 当前支持的模型

### 2.1 异常模型

- `IsolationForest`

用途：
- 识别偏离正常行为的样本

### 2.2 分类模型

- `RandomForestClassifier`

用途：
- 对样本输出恶意概率

---

## 3. 训练数据格式

当前训练脚本使用 CSV。

必须包含字段：

- `request_count_1m`
- `same_event_count_10m`
- `unique_dst_ports_5m`
- `login_failures_5m`
- `http_error_ratio_5m`
- `dns_query_length`
- `off_hours`
- `is_whitelisted`
- `asset_importance`
- `signature_severity`
- `baseline_score`
- `known_source`
- `known_event_type`
- `new_destination_ip`
- `new_destination_port`
- `label`

其中：

- `label=0` 表示正常
- `label=1` 表示异常/恶意

样例见：

- `tests/samples/training_features.csv`

---

## 4. 训练命令

### 4.1 只训练，不注册

```powershell
python scripts\train_models.py tests\samples\training_features.csv --out-dir models\trained
```

### 4.2 训练后直接注册并激活

```powershell
python scripts\train_models.py tests\samples\training_features.csv --out-dir models\trained --register --version sample-v1
```

### 4.3 手工导入已训练模型

```powershell
python scripts\import_model.py anomaly models\trained\anomaly_model.joblib --version trained-anomaly
python scripts\import_model.py classifier models\trained\classifier_model.joblib --version trained-classifier
```

## 5. 调优建议

### 5.1 优先调哪些参数

`config/app.yaml` 中：

- `risk.alert_threshold`
- `risk.block_threshold`
- `risk.weights.severity_per_level`
- `risk.weights.asset_importance`
- `risk.weights.anomaly_multiplier`
- `risk.weights.ml_anomaly_multiplier`
- `risk.weights.ml_classifier_multiplier`

### 5.2 建议方式

1. 固定数据集
2. 修改一项参数
3. 重跑样例
4. 对比风险分变化
5. 记录最优参数组合

### 5.3 开发环境建议

- 先保守
- 提高 `block_threshold`
- 缩短 TTL
- 打开 `dry_run`

### 5.4 真机环境建议

- 先跑告警
- 再开自动封禁
- 观察误报和回滚频率
- 分阶段调小/调大阈值
