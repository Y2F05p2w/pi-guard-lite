# Pi-Guard Lite 真机联调验收说明

## 1. 目标

树莓派到货后，用这份文档按顺序完成真机联调验收。

---

## 2. 联调前顺序

1. `bash scripts/bootstrap_rpi.sh`
2. `bash scripts/install.sh`
3. `bash scripts/install_systemd.sh`
4. `python scripts/preflight_check.py`
5. `python scripts/check_executor.py`
6. `python scripts/check_fluentbit_bridge.py`

---

## 3. 联调验收项

### 3.1 基础服务

- `/health` 正常
- `/executor/check` 正常
- `/ml/status` 正常
- `bash scripts/status.sh` 正常

### 3.2 Fluent Bit 链路

- Fluent Bit 进程正常
- `pi-guard-lite-fluentbit.service` 正常
- auth/syslog/nginx 日志可以进入系统

### 3.3 设备联动

- 手工封禁成功
- 手工解封成功
- block / unblock 命令实际生效

### 3.4 回滚能力

- probe 可访问核心目标
- 策略触发后可自动执行探测
- 异常时可回滚

### 3.5 稳定性与误伤

- `python scripts/run_false_positive_check.py`
- `python scripts/run_stability_check.py --iterations 50`

---

## 4. 验收通过标准

至少满足：

1. 真机服务正常启动
2. 日志输入正常
3. 封禁解封正常
4. 探测正常
5. 回滚正常
6. 无明显误伤
