# Pi-Guard Lite 稳定性测试说明

## 1. 目标

在树莓派到货前，先通过重复样例处理验证主链路能稳定运行。

---

## 2. 当前脚本

```powershell
python scripts\run_stability_check.py --iterations 10
```

输出：

- 总迭代次数
- 每轮样例数
- 事件总数
- 策略总数
- blocklist 总数

---

## 3. 推荐使用方式

### 开发环境

先运行：

```powershell
python scripts\create_demo_models.py
python scripts\run_stability_check.py --iterations 20
```

### 真机环境

到货后运行：

```bash
python scripts/run_stability_check.py --iterations 100
```

并同时观察：

- CPU
- 内存
- 温度
- SQLite 文件增长
- 日志增长

---

## 4. 通过标准

至少满足：

1. 无崩溃
2. 无明显异常退出
3. 事件总数与迭代次数一致
4. 无数据库锁死
5. 无明显资源泄漏
