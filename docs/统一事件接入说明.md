# Pi-Guard Lite 统一事件接入说明

## 1. 目标

为 Fluent Bit、外部脚本、测试工具和其他日志采集器提供统一原始事件接入入口。

---

## 2. 接口

### 2.1 单条事件

```text
POST /ingest/raw
```

请求示例：

```json
{
  "source": "auth.log",
  "payload": {
    "message": "Failed password for invalid user root from 203.0.113.55 port 55000 ssh2"
  },
  "apply_policy": false,
  "run_probe": false
}
```

### 2.2 批量事件

```text
POST /ingest/batch
```

请求示例：

```json
{
  "events": [
    {
      "source": "auth.log",
      "payload": {
        "message": "Failed password for invalid user root from 203.0.113.55 port 55000 ssh2"
      }
    },
    {
      "source": "syslog",
      "payload": {
        "message": "sudo: root : TTY=pts/0 ; PWD=/root ; USER=root ; COMMAND=/bin/id"
      }
    }
  ],
  "apply_policy": false,
  "run_probe": false
}
```

---

## 3. 安全控制

当 `config/app.yaml` 中配置了：

```yaml
ingest:
  auth_token: "your-token"
```

调用方必须在请求头中携带：

```text
x-pi-guard-token: your-token
```

---

## 4. 存储轮转

原始事件写入 `data/raw/` 时支持轮转：

- `retention.raw_rotate_max_mb`
- `retention.raw_rotate_max_lines`

文件命名示例：

```text
2026-04-02-001.jsonl
2026-04-02-002.jsonl
```
