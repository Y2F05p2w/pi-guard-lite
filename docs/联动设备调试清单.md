# Pi-Guard Lite 联动设备调试清单

## 1. 目标

本文档用于树莓派到货后，调试 OpenWrt / Linux 防火墙联动能力。

---

## 2. 配置准备

参考：

- `config/executor.yaml`
- `config/executor-openwrt.example.yaml`

至少确认：

1. 目标设备 IP
2. SSH 用户
3. 密钥或密码
4. `dry_run=false`
5. block / unblock 命令可在目标设备执行

---

## 3. 连接检查

```bash
python scripts/check_executor.py
```

如果只是想验证命令模板：

```bash
python scripts/check_executor.py --test-ip 203.0.113.200 --ttl 60
```

---

## 4. 推荐调试顺序

1. 先保持 `dry_run=true`
2. 确认 `/executor/check` 返回正常
3. 手工页面测试 `/manual/view`
4. 命令模板确认无误后改为 `dry_run=false`
5. 先短 TTL 测试
6. 观察目标设备是否正确写入封禁规则

---

## 5. OpenWrt 侧建议检查

1. `ipset list`
2. `iptables -S`
3. `nft list ruleset`
4. `logread`

---

## 6. 常见问题

### 连接失败
- SSH 密钥不对
- 路由器未开放 SSH
- 管理 IP 不可达

### 命令执行失败
- OpenWrt 没有安装对应组件
- 命令模板不适配
- 权限不足

### 能连接但没效果
- 命令执行到了错误的接口/链
- block 命令未绑定到实际转发路径

---

## 7. 真机联调建议

- 先测手工封禁
- 再测自动封禁
- 最后再打开自动回滚
