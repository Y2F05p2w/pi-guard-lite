# Pi-Guard Lite 自动扫描监听说明

## 1. 目标

启动项目后，让系统常驻监听一组 TCP 端口，等待另一台主机真实扫描，并自动进入分析链路。

---

## 2. 当前实现

新增：

- `scripts/run_scan_listener_service.py`
- `systemd/pi-guard-lite-scan-listener.service`
- `app/collector/scan_listener_service.py`

监听来源：

- `scan.listener`

进入链路后会继续执行：

- 解析
- 特征提取
- 规则检测
- 风险评分
- 策略生成
- 黑名单记录

---

## 3. 配置

位置：

- `config/app.yaml -> scan_listener`

```yaml
scan_listener:
  enabled: true
  auto_start_with_web: true
  bind_host: "0.0.0.0"
  report_host: "127.0.0.1"
  ports: "2201-2212"
```

---

## 4. Web 项目启动时自动带起

现在默认行为是：

- 启动 Web 项目
- 自动启动 scan listener
- 另一台主机直接扫描本机
- 系统自动进入分析链路

只要 `config/app.yaml` 中：

```yaml
scan_listener:
  enabled: true
  auto_start_with_web: true
```

然后正常启动 Web 即可：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8080
```

可检查状态：

```text
GET /scan-listener/status
```

---

## 5. 手工启动

```bash
python scripts/run_scan_listener_service.py --bind-host 0.0.0.0 --report-host 192.168.1.50 --ports 2201-2212
```

---

## 6. 使用 start.sh 自动启动

```bash
export PI_GUARD_SCAN_ENABLED=1
export PI_GUARD_SCAN_BIND_HOST=0.0.0.0
export PI_GUARD_SCAN_REPORT_HOST=192.168.1.50
export PI_GUARD_SCAN_PORTS=2201-2212
bash scripts/start.sh
```

---

## 7. systemd

项目已提供：

- `systemd/pi-guard-lite-scan-listener.service`

部署后可直接启用。

---

## 8. 适用场景

- 另一台主机对本机做真实端口扫描
- 无需手工重放样例
- 无需额外跑演示脚本
