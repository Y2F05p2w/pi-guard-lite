# Pi-Guard Lite 自动扫描监听说明

## 1. 目标

启动项目后，让系统常驻监听一组 TCP 端口，等待另一台主机真实扫描，并自动进入分析链路。

---

## 2. 当前实现

新增：

- `scripts/run_scan_listener_service.py`
- `systemd/pi-guard-lite-scan-listener.service`

监听来源：

- `scan.listener`

进入链路后会继续执行：

- 解析
- 特征提取
- 规则检测
- 风险评分
- 策略生成
- 黑名单记录

---

## 3. 配置

位置：

- `config/app.yaml -> scan_listener`

```yaml
scan_listener:
  enabled: false
  bind_host: "0.0.0.0"
  report_host: "127.0.0.1"
  ports: "2201-2212"
```

---

## 4. 手工启动

```bash
python scripts/run_scan_listener_service.py --bind-host 0.0.0.0 --report-host 192.168.1.50 --ports 2201-2212
```

---

## 5. 使用 start.sh 自动启动

```bash
export PI_GUARD_SCAN_ENABLED=1
export PI_GUARD_SCAN_BIND_HOST=0.0.0.0
export PI_GUARD_SCAN_REPORT_HOST=192.168.1.50
export PI_GUARD_SCAN_PORTS=2201-2212
bash scripts/start.sh
```

---

## 6. systemd

项目已提供：

- `systemd/pi-guard-lite-scan-listener.service`

部署后可直接启用。

---

## 7. 适用场景

- 另一台主机对本机做真实端口扫描
- 无需手工重放样例
- 无需额外跑演示脚本
