# Pi-Guard Lite 误伤与回滚测试说明

## 1. 目标

验证正常行为不会被错误封禁，且需要时能正确回滚。

---

## 2. 当前脚本

### 误伤检查

```powershell
python scripts\run_false_positive_check.py
```

该脚本会输入：

- 正常登录
- 正常 sudo
- 正常 HTTP 健康检查

并检查：

- 是否错误生成 `block_ip`
- 是否错误进入 blocklist

---

## 3. 推荐测试顺序

1. 先跑误伤检查
2. 再跑带 probe 的 Suricata 样例
3. 再人工检查策略与 blocklist
4. 真机到货后再补真实业务回滚场景

---

## 4. 通过标准

至少满足：

1. 正常输入不进入 blocklist
2. 正常输入不产生 `block_ip`
3. 回滚场景时可以恢复封禁

---

## 5. 真机阶段建议补充

1. 对真实健康接口做 probe
2. 对真实业务白名单做验证
3. 对 OpenWrt 真机封禁后做自动回滚验证
