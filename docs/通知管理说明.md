# Pi-Guard Lite 通知管理说明

## 1. 目标

用于配置和验证告警通知链路。

---

## 2. 当前支持

当前支持：

- Webhook 通知

配置位置：

- `config/app.yaml -> notifier`

---

## 3. 配置示例

```yaml
notifier:
  enabled: false
  channel: "webhook"
  webhook_url: ""
  timeout_seconds: 3
```

---

## 4. 页面与接口

### 页面

- `/notifications/view`

### 接口

- `GET /notifications/status`
- `POST /notifications/test`

---

## 5. 使用建议

1. 先配置测试 webhook
2. 用页面发送测试通知
3. 验证关键策略动作是否能触发通知
4. 真机环境再切换到正式 webhook

---

## 6. 测试

```powershell
python -m unittest tests\test_notifier.py
```
