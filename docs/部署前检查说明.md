# Pi-Guard Lite 部署前检查说明

## 1. 目标

在树莓派或 Linux 真机部署前，快速检查项目目录、配置、模型和 systemd 文件是否齐全。

---

## 2. 检查脚本

```powershell
python scripts\preflight_check.py
```

输出内容包括：

- 运行路径
- 模型路径
- 执行器配置
- Fluent Bit 配置
- systemd 单元文件

---

## 3. 推荐使用时机

1. 拉取代码后
2. 修改配置后
3. 导入模型后
4. 安装 systemd 前
5. 上线前最后一次自检

---

## 4. 通过标准

至少满足：

1. 关键路径存在
2. systemd 文件存在
3. executor 配置不为空
4. 模型路径与配置一致
5. Fluent Bit 配置存在
