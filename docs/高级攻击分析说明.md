# Pi-Guard Lite 高级攻击分析说明

## 1. 目标

在现有主链路基础上，为事件增加更高层的攻击行为分析、MITRE 映射和攻击图谱能力。

---

## 2. 当前已实现的高级分析能力

### 2.1 攻击路径图谱

系统会为每条事件生成：

- 图节点
  - 攻击源 IP
  - 目标资产
  - 检测发现
  - MITRE Technique
- 图边
  - `targets`
  - `has_finding`
  - `mapped_to`

### 2.2 MITRE ATT&CK 映射

当前已支持基础映射：

- `T1046` 网络服务扫描
- `T1110` 爆破
- `T1071.004` DNS
- `T1190` 公网应用利用
- `T1059` 命令执行
- `T1505.003` WebShell
- `T1548` 提权机制滥用
- `T1204` 用户执行

### 2.3 SQL 注入分析

根据 URL/参数中的典型注入关键词进行识别：

- `union select`
- `or 1=1`
- `information_schema`
- `sleep(`
- `benchmark(`

### 2.4 RCE 利用链分析

检测：

- `cmd=`
- `powershell`
- `/bin/sh`
- `bash -c`
- `wget http`
- `curl http`
- `whoami`

### 2.5 WebShell 分析

检测典型 WebShell 文件名：

- `shell.php`
- `cmd.php`
- `webshell`
- `c99.php`
- `r57.php`

### 2.6 文件木马/恶意样本基础分析

对 `sample.report` 源做基础分析：

- 高熵
- 可疑扩展名
- 样本元数据

### 2.7 EDR 级进程树基础关联

对 `edr.process` 源做父子进程关联：

- Web 服务进程拉起 shell
- shell/命令执行器衍生

### 2.8 横向移动基础识别

结合：

- 内网横向常见端口
- 多目标离散访问
- 新来源/新目标
- 登录行为

进行横向移动迹象识别。

### 2.9 全网资产关联溯源

当前以目标资产 IP / sensor 为主做基础关联，输出：

- `impacted_assets`

---

## 3. 接口

### 事件分析结果

```text
GET /analysis/event/{event_id}
```

返回：

- findings
- techniques
- graph_nodes
- graph_edges
- impacted_assets
- summary

---

## 4. 当前边界

当前属于**基础版高级分析**，适合：

- 边缘防御一体机
- 小型实验环境
- 样例/真机混合验证

还不等于完整企业级：

- 图数据库溯源平台
- 全网分布式 EDR
- 全量样本沙箱
- SOC 级 ATT&CK 知识库
